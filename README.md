# AI & Backend Developer Portfolio

A modern, professional portfolio website for AI and backend developers. Showcases machine learning expertise, API development, and scalable system architecture with a clean, futuristic design.

## 🚀 Features

- **Modern Design**: Clean UI/UX with glassmorphism and gradient effects
- **Responsive**: Fully responsive design for desktop, tablet, and mobile
- **Dark/Light Mode**: Toggle between themes with smooth transitions
- **Smooth Animations**: Scroll reveal animations and hover effects
- **Interactive Elements**:
  - Typing text animation
  - Sticky navigation
  - Mobile hamburger menu
  - Contact form with validation
  - Scroll to top button
- **Sections**:
  - Hero with animated background
  - About with skills progress bars
  - Services showcase
  - Portfolio gallery
  - Pricing plans
  - Customer testimonials
  - Contact form
  - Footer with social links

## 🛠️ Technologies Featured

- **AI/ML**: Python, TensorFlow, PyTorch, Scikit-learn
- **Backend**: FastAPI, Django, Node.js, PostgreSQL
- **Cloud**: AWS, Azure, Docker, Kubernetes
- **Data**: Apache Spark, Kafka, Redis, MongoDB
- **DevOps**: CI/CD, Monitoring, Container Orchestration

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Customize** the content to match your personal information
4. **Replace** Lorem Picsum URLs with your own images (optional - placeholder images are already included)
5. **Deploy** to your preferred hosting platform

## 🖼️ Images

The website includes real placeholder images from Lorem Picsum for immediate viewing:

- **Profile Image**: 300x300px professional headshot
- **Project Images**: 350x250px project screenshots/mockups  
- **Client Photos**: 50x50px client avatars

### Replacing Images

To use your own images:

1. Replace the Lorem Picsum URLs in `index.html` with your image paths
2. Or add your images to `images/assets/` and update the `src` attributes
3. Recommended sizes:
   - Profile: 300x300px (square)
   - Projects: 350x250px
   - Clients: 50x50px (square)

## 🎯 Customization

### Personal Information
- Update name, bio, and contact details in `index.html`
- Modify skills and experience in the About section
- Add your own projects to the Portfolio section
- Update testimonials with real client feedback

### Styling
- Colors can be modified using CSS custom properties in `:root`
- Adjust animations and transitions in `style.css`
- Modify responsive breakpoints as needed

### Images
- Replace placeholder images with your actual photos
- Recommended image sizes:
  - Profile image: 300x300px (square)
  - Project images: 350x250px
  - Client photos: 50x50px (square)
